# BlackBeard

The native test projects are:

- `ios/BlackBeard` — iPhone source and Xcode project.
- `android/BlackBeard` — Android source and Gradle project.

The installable Android test build is
`android/BlackBeard-Android-Test.apk`. It requires Android 7.0 or newer.

The GitHub repository and final degenerate.earth homepage link remain gated
until both device builds have been tested and approved.
